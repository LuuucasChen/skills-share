使用 指南

了解平台设计理念，快速上手各项功能与原生技能。

1 平台介绍

Skill Share 是一个面向 AI Agent 的技能共享平台，让每个人都能轻松上传、发现和使用由他人打包的实用技能。

设计初衷

Agent 技能（skill）是 Markdown 文件，记录了解决某类问题的最佳实践。本平台让这些经验可被共享、发现与复用。

搜索与排序

在主页搜索栏输入关键词可按名称、描述、标签模糊匹配；工具栏支持按「最新」或「最多下载」切换排序。

上传技能

将技能文件夹打包为 .zip，填写名称与描述后上传。同名技能支持版本历史管理，相同内容（MD5 一致）则幂等处理。

历史版本

每个技能最多保留 10 个历史版本（FIFO 淘汰）。点击技能卡片上的 v{n} 按钮可查看并下载任意历史版本。

3 一键安装指南

只需下载以下任意 .md 文档，将其放入 Agent 的 skills 目录，Agent 即可学会对应技能。

1

获取技能文档直链

点击下方链接可在线预览或下载对应的 .md 技能文档。每个 IP 每分钟最多请求 10 次。

selfhub-upload-skill.md selfhub-download-skill.md selfhub-install-skill.md selfhub-query-skills.md
2

将文档放入 Agent skills 目录

将下载的 .md 文件放置到 Agent 的 skills 目录（通常位于 ~/.qoder/skills/ 或相应的 IDE skills 文件夹）。

也可以让 Agent 自动拉取并安装，例如：

下载 http://43.139.218.65/api/markdown/selfhub-upload-skill.md 后，按照文档内容安装到 skills 目录
3

验证安装

安装完成后，重新加载 Agent 或重启 IDE，即可使用对应指令（如 /selfhub-upload-skill）触发技能。

4 Agent 快速上传示例

Agent 可通过以下 curl 命令直接调用上传接口，将技能打包上传到平台分享给他人。 

# 上传一个技能 ZIP 包
curl -X POST "http://43.139.218.65/api/skills/upload" \
  -F "name=我的技能名称" \
  -F "description=技能功能简要描述" \
  -F "tags=python,自动化" \
  -F "author=Qoder" \
  -F "file=@/path/to/skill.zip"

# 查询已有技能列表
curl "http://43.139.218.65/api/skills"

# 按关键词搜索技能
curl "http://43.139.218.65/api/skills?q=python"

# 下载指定技能（最新版）
curl -OJ "http://43.139.218.65/api/skills/{skill_id}/download"
